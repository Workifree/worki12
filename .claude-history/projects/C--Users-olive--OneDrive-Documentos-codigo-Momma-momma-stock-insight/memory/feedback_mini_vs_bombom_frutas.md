Na Momma, **"mini" e "bombom de frutas" são dois produtos distintos** — não tratar como o mesmo nem misturar receitas.

- **Bombom de frutas** (Uva, Morango): fruta + brigadeiro **PRETO 51%** (não branco) + casquinha de chocolate. Ex.: Uva = 30g brig preto + 10g uva + 8g choc; Morango = 20g morango + 30g brig preto + 12g choc.
- **Mini** (bombom recheado): casquinha **12g de chocolate preto 51%** (R$102/kg) + **25g de recheio**, em vários sabores (o sabor = o recheio). Sabores: Pistache, Prestígio, Brigadeiro, Brownie c/ Doce de Leite, Franuí, Pão de Mel, Ninho com Avelã, Torta de Limão, Caramelo Salgado, Mousse Maracujá, Brigadeiro Vegano, Pistache Vegano, Café.

**Why:** o usuário corrigiu explicitamente quando misturei os dois ao custear. **How to apply:** ao custear/cadastrar, manter fichas separadas; bombom de frutas usa brigadeiro preto; mini é casquinha+recheio. Ver [[project_custos_fichas_construtor_2026_06]].
