User's coding workflow (follow in order):
1. RESEARCH — market/tech research
2. PRD — business doc with use cases and metrics
3. TECHSPEC — map all touch points, files, functions
4. EXEC — break techspec into tasks, execute one by one
5. QUALITY GATE — verify implementation didn't deviate from plan
6. TRACKING — user analytics/conversion tracking
7. REVIEW — code review for patterns, architecture compliance
8. SEC — vulnerability scan

**Why:** Structured approach ensures nothing is missed and quality is maintained.
**How to apply:** Always know which step we're on. Don't skip steps. Each step builds on the previous documents.
