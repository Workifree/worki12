Quando o usuário pede estratégia/plano, dar UMA escolha clara com justificativa, NÃO um menu de opções para ele decidir.

**Why:** corrigido em conversa de renda extra (abr/2026). Eu listei 4 frentes paralelas + 4 nichos + setup fiscal — usuário respondeu "voce me deu mil opçõesmas qual é a que itneressa? seja sucinto direto claro". Ele quer eu fazer a escolha e justificar, não delegar a decisão de volta.

**How to apply:** ao recomendar estratégia, escolher A vencedora primeiro, apresentar como decisão, justificar em 1-2 linhas, listar descartados em 1-linha cada com o motivo. Tabelas comparativas só quando o usuário pede. Não terminar pergunta com "qual escolhe?" se eu posso escolher por ele com base nos critérios já dados.
